# 🎓 UniGrade V2

**UniGrade** is an Academic Evaluation and Semester Result Management System designed for educational institutions, supporting flexible academic grading and result management.

V2 is a complete React-based rebuild of the original UniGrade V1 project, with a focus on cleaner architecture, scalability, and expanded academic functionality.

---

## 🚀 V2 Goals

- Modern React-based architecture
- Flexible academic evaluation
- SGPA calculation
- Fixed / Absolute Grading
- Relative Grading
- Customizable grading systems
- Faculty workflows
- Institution workflows
- Student and academic record management
- CGPA calculation
- Multi-university support
- Support for different evaluation systems

---

## 🛠️ Tech Stack

- **React**
- **Vite**
- **React Router**
- **JavaScript**
- **CSS**
- **Firebase** *(planned / as required)*
